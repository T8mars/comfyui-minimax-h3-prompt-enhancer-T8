# T8 Storyboard Pack（分镜创作包）

输出全局提示词、逐镜 JSON、静态关键帧图像提示词以及转场/声音表。模型只生成一次逐镜合同，后两张交付表由节点在本地派生，避免重复付费输出。可接创作总纲和素材角色表；不会杜撰不存在的素材编号。

可连接影视项目状态与角色表演圣经。逐镜 JSON 额外包含因果连接、变化前/后价值、删除该镜头会破坏的功能、伏笔与回收；节点本地生成 `narrative_audit`，只报告结构覆盖和未匹配伏笔，不冒充客观创意评分。角色表演仍受每节拍最多三个可观察通道的限制。

连续性锚点必须逐字出现；同一伏笔与回收使用完全相同的短标签。顶层只接受 `global_prompt` 与 `shots`，若兼容接口擅自改成 `storyboard` / `shot_list` 等别名，会明确标记 `structured_response=false` 并保留诊断信息。

运行后节点底部会直接显示分镜协议状态。绿色表示镜头数量、时序、必填字段、线索预算和字面锚点均通过；红色表示至少一项不合格。状态卡会跟随 ComfyUI 的中英文界面，并按诊断内容自动增高。

`协议失败处理` 默认使用“警告并保留输出（兼容）”，不改变旧工作流；选择“严格阻止下游（推荐）”后，红色合同会通过 ComfyUI 原生阻断器停止下游，同时保留状态卡和 `shot_list_json.validation_errors`。状态卡和本地阻断都不产生额外付费请求。
