# T8 Character Performance Bible（角色表演圣经）

把一个当前角色的目标、阻力、失败代价、策略、身体任务、声音与倾听反应整理为轻量表演合同。节点本身不调用 LLM。

输入框里的中英双语文字是占位示例，不会写入输出；直接点击后输入自己的内容即可。

简明参考案例：

- 场景目标：让妹妹交出车钥匙。
- 阻力与失败代价：妹妹拒绝；失败就错过末班车。
- 策略阶梯：试探询问 → 提出交换 → 直接阻拦（在输入框中每行写一个）。
- 手头动作与身体惯性：收拾行李，同时压住发抖的手。
- 声音锁定：低声、短句，越紧张越慢。
- 面具破裂触发：听见父亲名字时笑容停住。
- 视线与倾听：避开姐姐目光；听到钥匙声后抬眼。

- 目标应是角色对搭档或障碍采取的动作，而不是“悲伤”“愤怒”等情绪标签。
- 每个节拍只使用一个主要策略；策略失败、新信息出现或权力变化后才切换。
- 下游每个角色每个节拍最多编译三个高信号可观察通道，避免微表情堆叠。
- 手头动作和身体状态会跨镜头保持惯性；声音锁定只在角色实际说话时使用。
- 用户提供的对白必须逐字保留，节点不会授权模型自行补写对白。

单角色紫色输出可直接连接 H3、Seedance 2.0 或 Storyboard Pack 的同名可选输入，不增加请求次数。多角色场景请先连接 `T8 多角色表演集合`：它最多汇总 8 个独立角色，拒绝重复角色标识，并要求逐镜分别保留每个角色的目标、策略和可观察线索，避免把不同角色揉成一个表演指令。
