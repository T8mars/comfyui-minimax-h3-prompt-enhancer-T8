# Experimental storyboard direction

Local config for H3 / Seedance `storyboard_director_config` only, not MOSS.
Default Off; disconnected/Off preserves existing behavior. On advises event coverage,
reveal timing, readable contact and continuity while retaining existing directors,
acting, exact dialogue, shot locks, first/last states and media roles.

No added duration cap, deliberate shortening of the target duration, automatic
splitting or separate planning request. Existing context and output-token limits still apply.
Input tokens and existing corrections can still cost resources. Existing 38-field
widget arrays and output ports remain unchanged. Recovery restores the old result,
not the current switch.

Non-official method with unverified benefit. Leaving a complete source unchanged is
valid. Compare Off/On under fixed conditions; longer prompts and more cuts are not
evidence of improvement.
