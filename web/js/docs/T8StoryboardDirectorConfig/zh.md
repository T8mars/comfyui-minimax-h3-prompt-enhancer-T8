# 分镜强化（实验）

纯本地配置节点，仅连接 H3 / Seedance 的 `storyboard_director_config`，不连接 MOSS。
默认关闭；未连接或关闭保留旧行为。开启后建议事件承载、信息揭示、接触可读性与跨镜状态，
不替换既有导演或情感演绎，不改用户对白、镜数、一镜到底、首尾和素材锁定。

不新增时长上限、不主动缩短目标时长、不自动拆片；原有上下文和输出 token 限制仍适用。
不增加独立规划请求，但输入 token 和原有修复可能产生费用。
原有 H3/Seedance 38 项控件与输出不变；恢复只取旧结果，不套当前开关。

方法非官方，未证明正收益；原稿完整时允许不改。先固定条件比较 Off/On，
不要把提示词长度或镜数增加当作质量改善。
