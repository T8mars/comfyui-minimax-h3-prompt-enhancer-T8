# 导演风格参考

“浏览风格与帮助”现在包含200条目的400个拍法图式：选择第1/2条方法，动态示意可拖动进度或手动播放/暂停，静态构图则禁用播放。默认不播放；切换/关闭自动停止。灰度图不是电影剧照、完整导演风格或模型实测，A/B与箭头只用于解释，不进入提示词。“真实生成对比”明确标未实测。

连接 H3 / Seedance 的 `creator_style_config`，默认关闭。点“浏览风格与帮助”查找并阅读具体拍法、职责和来源整理说明，应用后切为“开启 / On”。导演不会自动带入色彩，可与独立色卡自由组合。弱来源明确标注为通用镜头模板，不称独有导演理论。

提供构图、拍法和节奏建议，不是完整编剧器。不新增剧情、人物、台词、年代或渲染媒介。原事实、LOCK、时长、镜数与结尾优先；单镜过滤需切镜方法，其他语义仍需检查。无独立模型请求、不限时长、不接MOSS。更新后重启；恢复原稿不采用当前选择。

示例：`visual_style_creator_seedance20.json`、`visual_style_combined_h3.json`。默认Off、空Key、一个增强器。真实模型/成片效果未验证。
