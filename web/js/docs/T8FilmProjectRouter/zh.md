# T8 Film Project Router（影视项目状态路由）

纯本地维护影视项目阶段、权威输入、世界规则、连续性锚点与修订影响，不调用 LLM，也不会读取磁盘项目或自动重做下游。

- “本轮权威输入”只登记用户明确确认的资料；缺失内容保持未知。
- 修改一个上游阶段时，节点按依赖图列出可能失效的下游，但不会删除或重写任何结果。
- 把紫色 `film_project_state` 连接到 Long-form Planner 或 Storyboard Pack，可传递世界规则、能力代价、人物知情差和失效状态。
- 要建立新修订，推荐把上一轮紫色 `film_project_state` 直接接到“上一版项目状态”；也可复制“项目状态 JSON”。两种来源同时提供时必须完全一致。
- 接力时，当前留空的项目简述、权威输入、已确认阶段、世界合同和连续性锚点自动继承；不会只保留修订号而丢失项目事实。
- 如果要删除上一版中的某一项，而不是继续继承，请在该字段单独输入 `[清空继承]`。只会清空这个字段，其他留空字段仍继续继承；英文标记 `[CLEAR_INHERITED]` 也可使用。
- 运行后节点底部直接显示修订号、状态来源和已失效下游阶段。红色状态卡表示需要重新确认，绿色表示本轮未触发失效；状态卡跟随 ComfyUI 中英文界面并按内容自动增高，不会再遮挡较长的失效/清空列表。

状态 JSON 不得包含 API Key。节点检测到类似密钥的文本会在本地拒绝执行。
