# Seedance 2.0 提示词增强器（T8）

根据 Seedance 2.0 的任务意图、素材引用语法和镜头组织方式，生成一段可直接下游使用的提示词。

- 支持文字、图像和视频输入；本地 GGUF 使用采样帧视觉分析且不读取音轨。
- 本地模型递归扫描 `ComfyUI/models/LLM`；视觉模型可用 `AUTO（自动匹配）`选择对应 mmproj。
- `AUTO` 可判断任务意图、时长、复杂度和镜头数；固定镜头数 1–20 是软约束。
- 图片始终可内联 Base64；OpenAI 兼容模式可为视频提供逐行素材 URL。
- 非官方 T8 模板只迁移机制、节奏和 Creative DNA，不复制来源人物、剧情或媒体。
- “恢复上次云端结果（不重新生成）”只读取当前进程中本节点的完整内存结果，不会再次调用提示词增强 API；残缺流或零字节响应不会伪装成成功。
- 云端与本地都会执行最终语言锁；完整结果明显跑错语种时最多追加一次低温语言纠正，网络状态未知时不会借此重投。Seedance SSE 固定从原始字节按 UTF-8 解码。

输出为 `enhanced_prompt` STRING。上游返回非空内容即保留，不因精确字数或字段偏差将可用内容判为失败。
