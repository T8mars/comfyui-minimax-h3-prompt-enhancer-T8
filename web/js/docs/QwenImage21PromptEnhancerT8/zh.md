# Qwen Image 2.1 提示词增强器

把本节点接到图像生成或图像编辑节点之前使用。

- 选择「文生图」，并保持有序参考图输入为空，即可只根据文字创作。
- 选择「图像编辑」后可连接 1–10 张 `IMAGE`。节点会保留每张图的顺序，不会静默丢图。
- 「最大提示词字数」为 `0` 时让模型按 Skill 自行决定完整长度；填写上限时最多进行一次有界纠正，不在本地截断句子。
- 比例选 `auto` 时交给 Skill 选择横向或竖向比例；固定比例只放在 `wh_ratio` 输出，不写进正文。
- 只有确实需要透明背景和 Alpha 通道时才打开「透明 RGBA」。

默认云端渠道是贞贞平价小屋，模型为 `qwen/qwen3.8-flash-next`。共享渠道配置可切换贞贞 AI 工坊、OpenAI 兼容接口或本地 GGUF。云端默认 8192 个输出 Token（包含思考）；共享配置明确填写 `max_tokens` 或 `max_completion_tokens` 时以该值为准。

四个输出依次为英文图像提示词、最终比例、脱敏请求说明和脱敏增强报告；不会把 API Key 或完整响应正文写入输出。
