# H3 手动空间画框

独立于 audio 插件。先在本节点上传/选择图片，再点击 **🖱 手动画框 / Edit spatial regions**。
人物框、目标框、描述、颜色与动作关系都可在界面填写，不必写JSON。

1. 点“＋人物框”或“＋目标框”再在图上拖矩形；选择状态拖内部移动、拖八个控制点缩放。
2. 填写每个框的描述，点“＋添加动作关系”，选择人物和目标并填写动作与最后状态。
3. 可撤销/重做；“实际标记图”是本地CPU预览，不调用模型。已有标记图模式不会重画原图。
4. “应用并完成”写回节点，随后保存工作流。关窗前未应用的修改会询问是否放弃。
5. marked_image → H3参考图；marker_plan → 原空间配置 → H3.visual_marker_config。原空间配置默认Off，需手动On。
6. Hybrid可将source_image接首帧；它是当前上传源图，不自动擦框。配置自己的文本增强渠道再运行。

坐标是源图0..1矩形，叠加标记而非裁切图片。v1单张静态RGB、最多4MP；不自动缩放或限制视频时长。
预览与执行使用同一CPU/EXIF/RGB路径，应用会绑定源RGB摘要。换图后必须重新加载并核对框选；不会静默复用旧图绑定。
外部连线驱动字段时，编辑器不覆写隐藏值或拆线。预览只读Comfy input目录，图片只在本机后端和浏览器间传输；增强云请求仍按原渠道发送图与标记文本。

marker_plan供本项目增强配置使用；audio的Prompt/Bind有自己的Python计划类，不能把本计划直接冒充那个对象。
需要接它时，用本节点source_image、markers_json接其原Prepare，匹配绘框模式/线宽，重建那边的计划；两个项目均无需跨改。
不生成视频，不保证硬轨迹、人物语义或去框。
