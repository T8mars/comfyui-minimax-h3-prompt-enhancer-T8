# 表演导演配置

将输出连接到 H3、Seedance 或 T8 Storyboard Pack 的“表演导演配置”可选输入。
本节点不调用模型、不要求 API Key；选择会影响下一次增强请求，不改已有缓存结果。

- AUTO：默认，仅对确有角色/表演意图的内容启用。
- 强化：明确现有表演的触发、接收、反应。
- 关闭：不加表演导演规则。
- 极致：重构较弱的表演因果与节拍，保留事实和原句。
- 土豆-情绪演绎（声画协同）：区分情绪质地、强度和音量，衔接前后余绪，协调每句演法、口型及可见动作；不是“比极致更激烈”。

例如：输入“她含泪低声说‘我知道了。’，不哭腔”。新模式会引导眼眶含泪但声音清楚、说完仍有余绪，不把“含泪”一律写成抽泣，也不添加台词。已经完整的表演稿可以保持不变。

角色表演圣经是可选的角色约束，不用全部填写；它和情绪模式可以一起用。独立戏剧/战斗 Skill 决定创作方法，情绪模式负责人物演法；都不能覆盖原句、声音许可、镜头数、时长及首尾帧。无人物的请求不会被强加表情或声音。

H3 和 Seedance 各用自己的输出格式；Storyboard 沿用既有表演 IR。新模式不自动安装 LoRA、不改变素材顺序，也不增加规划或评分请求。原有语言/格式/质量纠正仍可能产生额外调用；质量未通过不是成片效果保证，按原流程保留可用稿并报告状态。

H3 会免费自动修复全角编号、明确归属的漏号和已知语言标签别名，质量 Off 也生效，不改原台词。多人归属不明确时保留完整稿并提示，不猜角色；可用已有“质量纠正”进一步处理，最多追加一次请求，不会悄悄开启。Seedance 仍用自然语言，不加入 H3 编号。
