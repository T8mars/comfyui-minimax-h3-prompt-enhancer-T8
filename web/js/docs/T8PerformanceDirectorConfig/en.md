# Performance director configuration

Connect the output to the optional performance configuration input on H3, Seedance or T8 Storyboard Pack. This config node does not call a model or need a key. It affects the next enhancement, not a cached answer.

- AUTO: default, applies only to actual character/performance requests.
- Strong: explicitly organize the existing trigger, reception and response.
- Off: add no performance direction.
- Extreme: restructure weak acting causality and timing while protecting facts and exact lines.
- Tudou emotion direction (Chinese option: 土豆-情绪演绎（声画协同）): separate emotion quality/intensity from vocal volume, carry emotional residue between states, and coordinate each line, lip motion and visible action. This is not a stronger intensity tier.

Example: “She tearfully whispers ‘I understand.’, without a crying voice.” The new mode guides moist eyes with clear speech and a lingering aftermath, rather than automatically adding sobs or dialogue. A complete well-directed passage may remain unchanged.

An optional character Bible constrains existing roles; there is no requirement to fill every field. Independent drama/combat Skills select the scene method; this mode handles acting. Exact lines, sound permissions, timing, shot count, media roles and keyframe locks retain priority. Non-character requests gain no face, emotion or voice.

Each platform keeps its native format; storyboard uses existing compact performance IR. No automatic LoRA installation, media reordering, planning call or scoring call is added. Existing language/format/quality corrections can still make extra calls. A retained draft is not a quality pass or proof of rendered improvement.

H3 automatically fixes fullwidth IDs, safely bound missing IDs and explicit language-tag aliases for free, even with Quality Off. Actual words are unchanged. Ambiguous multiple voices retain their complete draft and a diagnostic, not guessed identities. Optional Quality Repair still allows at most one extra request. Seedance remains natural language, without H3 speaker tags.
