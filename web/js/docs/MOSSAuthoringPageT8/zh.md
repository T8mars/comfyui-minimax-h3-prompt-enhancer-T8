# MOSS 选页与原生编译

Director 输出 0 `bundle_json` → 本节点同名输入；也可粘贴**完整 bundle** 离线使用。
无需 provider、模型或参考图片，不做动态提示词展开。失败检查稿不是完整 bundle。

`page_index` 从 1 开始，`language` 选择实际存在的 `en` 或 `zh`。
Comic 新生成页为英中双语；Fisher 通常只有一种语言。缺语言会报错，不自动翻译或回退。
需要同时取多页/双语时，并列放多个本节点。

| 输出序号 | 内容与用途 |
| --- | --- |
| 0 | `positive_prompt`：**仅此输出接 MOSS 正向文本编码** |
| 1 / 2 | `width` / `height`：INT，接实际画布 |
| 3 | `resolved_format`：caption 或 layout |
| 4 | `native_draft_json`：可编辑原生草稿，不是正向 |
| 5 | `report_json`：选择/结构诊断，不是正向 |
| 6 | `source_json`：保留漫画源标签的所选源稿，不是正向 |
| 7 / 8 | 当前页英中阅读稿 / 稳定 `unit_id`，用于审稿或修订 |

每次先校验完整集合，再编译选定源稿，零模型调用、不改其他单元。
描述字数按原稿历史设置显示，不把当前 UI 设置套进旧结果。
8 像素倍数的源宽高原样输出；下游 latent 可能另行对齐，精确排版请核实实际尺寸。

编译成功只证明结构可用，不证明翻译语义、审美、文字渲染或目标 4096 Token 不截断。
不要把整册、源 JSON、报告或阅读稿接正向，也不要把已编译居中坐标当原始草稿再编译。
