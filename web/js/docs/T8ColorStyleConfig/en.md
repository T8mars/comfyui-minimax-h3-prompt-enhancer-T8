# Color style config

Connect `color_style_config` to H3 / Seedance. It defaults Off. Browse, search, preview, Apply, then switch On.

Ordinary H3 On requests concrete palette placement on existing visible surfaces. Version 1.40.0 keeps the earlier experimental instructions and adds open-color clarification: unspecified colors can be completed from the palette, while protected original/reference colors, unknown states and materials prevail. The legacy On (H3 experimental) choice uses the same current instructions. To stop applying color, switch Off and regenerate.

Primary shares are soft references, not LUTs or pixel coverage. Accent swatches are preview-only. Lighting is separately opt-in. Locked colors, skin, timing, shot count and user facts prevail.

Local helper/browser: zero model calls, no image modification, duration cap or MOSS integration. Selected rules join the original request; no separate style request is added. Off and Seedance generation text are unchanged. Restart after upgrades. Recovery retains historical output and selection.

Examples: `visual_style_color_h3.json`, `visual_style_combined_h3.json`. One enhancer, blank keys, default Off. Configure your provider first.

See the [full guide](https://github.com/T8mars/comfyui-minimax-h3-prompt-enhancer-T8/blob/main/docs/visual-styles.md#style-validation) for prompt-validation progress, model settings and historical limitations. The preview's untested label refers to real rendered comparisons.
