# Color style config

Connect `color_style_config` to H3 / Seedance, default Off. Browse, search, preview, Apply, then switch On. Primary shares are soft references, not LUTs or pixel coverage. Accent swatches are preview-only. Lighting is separately opt-in. Locked colors, skin, timing, shot count and user facts prevail.

Local helper/browser: zero model calls, no image modification, duration cap or MOSS integration. Selected rules join the original request; existing correction budgets remain. Restart after upgrades. Recovery retains historical output.

Examples: `visual_style_color_h3.json`, `visual_style_combined_h3.json`. One enhancer, blank keys, default Off. Configure your provider first. Real model compliance and rendered benefits are unverified.
