# 色彩风格配置

连接 H3 / Seedance 的 `color_style_config`，默认关闭。点“浏览风格与帮助”搜索、预览、应用，再切为“开启 / On”。六色比例只是配色软参考，不是 LUT 或像素占比；四个候选点缀色只预览。默认仅色彩，“色彩 + 光影”才带入兼容光影建议。锁定服装、品牌色、肤色、时长、镜数与原事实优先。

配置和预览零模型调用，不修改原图、不限时长、不接 MOSS。规则加入已有增强请求，原修复预算不变。更新插件后重启；恢复原稿沿用历史选择。

示例：`visual_style_color_h3.json`、`visual_style_combined_h3.json`。每例一个增强器、空Key、默认Off；先设置自己的渠道。真实模型遵从与成片正收益未验证。
