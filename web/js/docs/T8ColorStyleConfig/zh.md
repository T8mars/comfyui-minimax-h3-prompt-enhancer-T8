# 色彩风格配置

连接 H3 / Seedance 的 `color_style_config`，默认关闭。点“浏览风格与帮助”搜索、预览、应用，再切为“开启 / On”。

H3 普通 On 要求把所选配色写到已有可见表面。1.40.0 沿用旧试验执行提示，并增加开放颜色补全说明：未指定或待定的颜色可以从色卡补全，明确保留的原色、参考色、未知状态及材质仍优先。旧“开启（H3强化试验）”在本版与普通 On 使用相同提示。停用请切 Off 并重新生成。

“浏览风格与帮助”现在包含200种配色的同场景矢量对照：中性基准/所选配色，可切换室内、街景和光影示意。仅为配色教学，不是模型实测或LUT；皮肤与衣服不变。弹窗切换不修改节点作用范围，浏览零模型调用。“真实生成对比”明确标未实测。

六色比例只是配色软参考，不是 LUT 或像素占比；四个候选点缀色只预览。默认仅色彩，“色彩 + 光影”才带入兼容光影建议。锁定服装、品牌色、肤色、时长、镜数与原事实优先。

配置和预览零模型调用，不修改原图、不限时长、不接 MOSS。规则加入已有增强请求，无独立风格请求；Off 与 Seedance 的生成文本不变。更新插件后重启；恢复上次结果保留历史文本与选择。

示例：`visual_style_color_h3.json`、`visual_style_combined_h3.json`。每例一个增强器、空Key、默认Off；先设置自己的渠道。

提示词验证进度、模型参数与历史限制见[详细使用说明](https://github.com/T8mars/comfyui-minimax-h3-prompt-enhancer-T8/blob/main/docs/visual-styles.md#style-validation)。预览“未实测”指真实生成视频对比。
