# H3 Hybrid：实施与真实 A/B 验收

日期：2026-10-06，Asia/Shanghai。此为未发布工作区验收，不是远端 Actions、
正式 Registry 下载包、RunningHub 部署或 H3 成片验收。

## 结论与使用方法

Hybrid 已作为原 H3 提示词增强节点的新生成类型接入：首帧和/或尾帧，另加
至少一份额外参考图片或视频。保留原五种任务、T2VA 默认、38 个保存字段、
端口、执行签名及原工作流。没有另造主节点，也不自动切换下游任务。
支持现有四渠道、共享配置、本地视觉预算、语言修复、质量检查/纠正、
Prompt Relay、上次结果恢复；增加三个独立示例和中英文说明。

重启 ComfyUI 并刷新网页后选择 Hybrid；下游 H3 音频生成插件也选 Hybrid，
连入同样角色、顺序的素材。详见[使用指南](h3-hybrid.md)。只有关键帧仍用
原 I2VA/FL2VA/L2VA，只有普通参考仍用 Ref2VA。本增强器不分析音轨。

本轮真实 API 24 次首发全部成功，角色编号与六段检查通过，但人工审阅
发现参考用途越界、视频事实误归因和个别几何错误。**不能宣称语义全通过、
Hybrid 全面胜出或成片质量满分。**这些问题在检查器的 unchecked 范围内，
没有靠删掉问题稿或补跑替换来提高结果。提示词需人工核对。

## 固定测试设置与原始证据

- 调用生产 `enhance_prompt` 及原上传、请求、流式解析、语言/质量路径。
  观测包装只记录脱敏指标，不替换远端模型返回值。
- 贞贞平价小屋，请求/响应模型均为 `bytedance/doubao-seed-evolving`，
  `stream=true`、`temperature=0.7`。请求未传 provider-native seed、
  max_tokens 或 reasoning_effort；文本里的写作种子 10060/10061 不能保证采样一致。
- 六种素材组合：首帧/尾帧/首尾帧 × 额外参考图/参考视频；每组两次，
  每次分别运行有效 Ref2VA 对照和 Hybrid。固定先对照后 Hybrid，非盲评、
  非均衡请求顺序，不作统计显著性或总体胜率结论。
- 两组输入同样的实际素材、8 秒、1 镜头、中文、balanced、字数自动、
  相同文本意图及角色上下文。对照把关键帧图作为 Ref2VA 参考上传，并明确
  其首尾用途；不是无效的“FL2VA 硬塞额外参考”。Hybrid 使用实际首尾端口。
- 意图：白底、灰轨、右侧蓝框、红色圆片；连续向右平移并减速，物体大小/
  方向/蓝框位置不变，不增物、不瞬移、不变形，严格遵守实际提供的首尾，
  一个固定镜头，无对白、文字、音乐，仅轻微摩擦声。参考图仅供外观，
  视频仅供滑动节奏。完整固定文本和素材生成代码见
  [`tools/h3_hybrid_acceptance.py`](../tools/h3_hybrid_acceptance.py)。
- 开启已有质量纠正，实验设全局最多 12 次追加逻辑请求、48 次聊天 HTTP
  尝试，认证失败即停止。实际均未触发；线上默认仍不替用户开启纠正。

## 素材事实与统一尺度审阅

三张实际 PNG 均为 512×256：圆片半径 24，圆心 y128，分别 x70（首）、
x390（尾）、x230（参考）；轨道端点 x40/x470，蓝框 x350..435/y85..170。
MP4 为 8 秒、16 帧、2fps，圆片按等步长从 x70 移到 x390；解码后每
0.5 秒约移动 21–22 像素，**源视频是近恒速，不是持续减速**。
用户要求的目标减速是合法改写，不能被写成源素材中的观察事实。
末段确有编码压缩杂色，不等于真实粒子、物体变化或错传视频。

## 修复、兼容与工程门禁

开发中已复现并修复：不可用图像尺寸/通道、空/非二进制/超容量视频在覆盖
付费缓存前预检；非消耗式流检查保持位置；语言纠正完整保留原意和素材角色，
不让正文里同名字符串伪造“已保留”；Hybrid Relay 拒绝六段混入第七段。
纠正失败保留完整旧稿并报告，不伪装成功，不默认重复生成。

冻结 1.29.2 基线 `d6ad140020f39da6182fe4dfd3e2ded11c5f5557`：旧五种任务的
请求文本与全部现有可选导演/表演/运镜对照不变，旧字段及示例保持冻结。
两条 CI 显式获取该基线，防止浅检出缺历史提交。官方 Skill 四文件及
`ref-en.txt` hash 未改；Hybrid 增补在独立 T8 模块，不冒充官方原文。

788 项 Python：786 通过、2 项外部解析器 opt-in 跳过，73.619 秒；
54 项前端、真实 Chrome configure/serialize、示例、JSON/密钥扫描通过。
保存字段/运行时 widget 重排、外接 STRING 的校验期 None、重复重载、
四路径传输、本地预算不丢素材、Relay 请求结尾与 padding、缓存原稿恢复
均有回归。24 份真实稿另做零网络重放，不重新付费。

候选 ZIP CRC 和隔离 CPU 安装验证 29 个节点、Hybrid 模块/示例、8 个官方
GIF、0 个 T8 GIF，无 GGUF/roadmap/私人交接文档，无本仓库运行时回退。
这是候选安装验证，不是正式 Registry 发布成功。
