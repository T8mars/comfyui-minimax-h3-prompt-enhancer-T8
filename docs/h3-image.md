# MiniMax H3 Image 提示词扩写

搜索 **MiniMax H3 Image Prompt Enhancer T8**，分类 `T8/H3 Image`。
这是独立图像提示词节点，支持文生图和图像编辑。它不生成图片，也不改变
H3 视频、MOSS 或其他节点的提示词规则。

## 快速使用

1. 文生图：输入创作需求；不要连接参考图。
2. 图像编辑：选择“图像编辑”，每个参考槽连接一张 IMAGE，最多 16 张。
   槽按编号排序，连续映射为 `<Picture 1>`、`<Picture 2>` 等；批次须先拆成单图。
3. 选择现有云渠道、OpenAI 兼容接口、本地 GGUF 或 Strata。共享
   `T8 LLM Provider Config` 优先于节点内设置。自定义配置生产者无法静态识别时，显示“共享配置（执行时确定）”。本地无需云 Key；编辑需要视觉模型和匹配投影器。
4. `expanded_prompt` 接下游 H3 正向提示词，也可接 `T8 Show Text` 预览。
   **编辑用的同一组原图仍需按同一顺序接下游编辑节点**，本节点不传递或绑定图片。

`T8 Prompt Text` 按原文传递 URL、JSON、大括号和多行文本。它不再运行宿主动态提示词语法，
例如 `{red|blue}` 会完整保留；需要随机变体时请使用专门的上游动态提示词节点。

示例已连好文字预览：

- [文生图](../example_workflows/h3_image_t2i_example.json)：中文标题咖啡海报。
- [双图编辑](../example_workflows/h3_image_edit_example.json)：图 1 构图，图 2 供色。
  请先把随附 [构图图](../example_workflows/h3_image_reference_canvas.png) 和
  [配色图](../example_workflows/h3_image_reference_palette.png) 上传到两个 LoadImage。
  这两张几何图由本项目创建，用于解释图序和测试，不是生成效果展示。

## 控制与输出

| 控制 | 含义 |
| --- | --- |
| 目标英文词数 | 0 沿用官方自动规则；正数是软目标，没有 1000 上限。不截断正文或删掉必要信息凑字数。统计正文中的拉丁文字词组，不是中文字符数或 Token。 |
| 画幅比例 | `auto` 自动选择。文生图仅支持官方十种比例：1:1、5:4、4:3、3:2、16:9、21:9、4:5、3:4、2:3、9:16。编辑允许任意正整数 W:H；显式输入原样保留。 |
| 逐字锁定文案 | 高级设置，每行一段非空画面文字，支持常规及 Unicode 换行。保留行内字符、顺序和重复次数；行内首尾空格也参与检查。空行和排版语义不做机械认证。 |
| 最多追加纠正 | 0 或 1，默认 1。完整回答的格式/比例/锁文案错误可以追加一次；网络失败和截断不自动重发。词数偏差不会单独触发纠错。 |
| 生成 Token | 云端、本地、Strata 各使用对应设置；本地上下文需容纳官方长指令、全部参考图和输出。不能容纳时明确报错，不偷偷丢图。 |

官方要求**英文描述正文**；画面中的中文、标题和其他原文保留原语言。
编辑输出描述保留的来源元素与改动；Subject 是语义对象，不与图片数量一一对应。

| 输出 | 用法 |
| --- | --- |
| `expanded_prompt` | 扩写正文，接 H3 正向提示词。 |
| `aspect_ratio` | 输出画幅比例，不会自动调整下游尺寸。 |
| `official_json` | 文生图为 `expanded_caption` + `aspect_ratio`；编辑为 `expanded_caption` + `target_aspect_ratio`。 |
| `report_json` | 来源版本、图片槽映射、字数偏差、调用数、预算及检查范围。不要接正向提示词。 |

恢复按钮读取当前 ComfyUI 进程内最近一次成功结果，不应用修改后的设置，
不重新调用模型。共享缓存最多 50 槽、通常一小时，重启失效；超大结果可正常输出但无法缓存。
失败不以未通过校验的草稿冒充成功。
复制整张工作流后，副本使用独立恢复槽；切回原工作流不会恢复副本的结果。
升级前没有工作流归属记录的旧槽首次加载时会失效，请正常生成一次；重启也会清空进程缓存。

## 来源与验证边界

官方资源位于 [MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE)，
不是主模型 README 中的一段通用扩写文案。文生图有独立 system/task；编辑使用独立长任务指令，
按官方方式交错传入图片、输入图比例和 JSON 编码的编辑需求。

PE 固定版本 `35603d4b63949afa12cb098227fffefedf081afa`；图像模型资料固定版本
`622d674eade1bdc87b7aac3a6fbee2b0fa99e28c`。原始文件逐字节保存在
[h3_image_vendor](../h3_image_vendor/source.json)，运行前验证哈希。
上游适用 [Community License](../h3_image_vendor/LICENSE)。T8 控制在适配层单独追加，
不修改官方快照，不捆绑或自动下载权重。

官方公开的编辑 PE 当前是提示词方案；接现有通用模型不等同于运行官方 PE 权重。
结构、明确比例和锁定文字通过检查，不证明模型理解、最终画面、身份保真或美学质量。
官方 H3 图像下游有 4096 Token 文本边界；这里没有运行匹配分词器，不把词数或增强模型预算当作防截断证明。
