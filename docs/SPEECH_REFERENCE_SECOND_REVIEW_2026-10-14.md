2026-10-14，用户再次要求“开个子 AGENT 检查 20 轮，有 BUG 修复”。本轮主审覆盖输入、字幕、预算、只读端点和前端；独立子 Agent 覆盖输出、纠正、Relay、取消与三种增强后端。以不同主题和可执行正反例分轮，交换反证后修复，不把同一用例重复执行当作 20 轮。

范围是当前待发布的可选语音／字幕功能及其增强集成，不声称已经证明全项目没有 BUG。版本仍为 **1.31.1**，未 stage、commit、push 或发布。本轮未改动、重启、卸载用户的 Strata 服务和模型，也未进行真实 ASR／LLM 推理。[第一阶段实测](SPEECH_REFERENCE_ACCEPTANCE_2026-10-14.md) 与 [第一次追加检查](SPEECH_REFERENCE_CROSS_REVIEW_2026-10-14.md) 的原始成功和失败记录均保留。

## 本轮复现并修复的根因

以下按根因合并为 15 类；一个根因在多个检查位置发生，不重复计为多个 BUG。均有先失败后通过的本地反例，属于合同／解析／传输行为证据，不是新模型效果评分。

### 输入、端点与保存：7 类

1. **无时标 JSON 擦掉 partial／复核状态。** 导入已规范化的 untimed JSON 时，旧分支递归按 plain 文本重建，变成 complete、无需复核。现在保留原状态和警告，partial 默认拒绝，只有显式接受且具备复核标记才通过；不能用 JSON 绕过策略。
2. **SRT 导出把有效短 cue 四舍五入成零时长。** 亚毫秒区间两端可能落在同一毫秒。仅导出 SRT 时保证至少 1ms，24 小时边界不溢出；原 JSON 浮点时标与原词不变。这不是提高了对齐精度。
3. **坏字幕分块把第二条时间码变成台词。** 缺少 cue 间空行时，第二条独立时间码会被第一条吞入正文。现在明确拒绝并要求修正分块；正常空行分隔的字幕继续接受，不猜测修复原词。
4. **预算在大结构展开／完整编码后才生效。** 现在先检查待展开容器的节点预算，并逐块累计 UTF-8 JSON 编码量，超限即停；不再先构建完整超大编码文本。保留原有深度、非法 Unicode、非有限值与循环输入拒绝。
5. **损坏的命名保存信息遮蔽合法位置数组。** 空或不完整的 helper 命名元数据会抢先被采用，丢失原有设置。现在只采纳完整、类型与判别值有效的 16 字段命名状态，否则回退到已校验的位置布局；同步按运行时 widget 名恢复，不靠声明次序。
6. **只读语音检查只限制压缩前 Content-Length。** 实际 aiohttp 端点接收 gzip 后，解压正文可超过声明的 8KiB 预算。现在累计读取解压后正文、超限拒绝，且不访问 Strata；小型合法压缩请求仍通过。不把这一改动说成整个 HTTP 栈的内存安全证明。
7. **只读检查接受重复 JSON 设置键。** 原生 JSON 解码会静默后值覆盖前值。现在采用现有严格解析器拒绝重复键和非有限常量，避免歧义配置。旧图文 Strata 状态端点本轮不改。

### 输出与增强集成：8 类

1. **原词内部再次识别发声动作。** Seedance `{他说：你好。}` 中的“他说”被重复解析成额外一句。改用不重叠 token span，原句内的谓词仍是数据。
2. **平衡嵌套花括号丢词。** `{使用{value}变量。}` 只取出内层文字。现在有界扫描完整原句；未知未闭合外层不会把内层提升为合法对白。不承诺下游视频模型／渲染器支持任意嵌套语法。
3. **H3 同词授权绑定到错误出现位置。** 同词的展示、正向发声、禁止发声混合时，按全文检索会多授权或漏授权。现在按各 native event／quote 的原位置分别匹配，显示引用也保留位置，不借另一处同词的语境授权。
4. **reference 模式漏数同 take 内重复。** 一次发声内把参考原句重复两遍，只算一个 take。现在按非重叠原词出现次数核对；用户明确要求的完整长句或重复句仍可授权，不自动把参考文字变成旁白。
5. **音景否定跨越转折词。** “没有音乐但旁白贯穿”被前面的“没有”整体否定。现在按转折分句判断，实际旁白仍不能藏进环境音／配乐层；“没有音乐但没有旁白”对照不误拒。
6. **发声原词参与描述语言／协议判断。** 长中文锁词会使合法英文描述多触发纠正；原词中的 `(S1)` 又会误判为外层 H3 协议，真正外层孤立 `<d>` 反而可能被旧 literal mask 漏掉。新增仅在语音启用时使用的语言／Seedance 质量适配器，分离对白数据、显示引用与实际结构；保留 source literal、固定镜头数和空描述检查。主审同时接入前置语言检查与质量流程，同一根因不分账成三个 BUG。
7. **Relay 错误承载面代替事件对白。** 把锁词塞进 global_prompt 或 end_state，可让 event.prompt 没对白仍通过。启用语音时分别检查承载面，实际发声须在事件 prompt；画面标题等显示引用不误算发声。旧 Relay 编译器和关闭路径不变。
8. **次要异常分支里的取消被吞。** 显式 cause 是普通 timeout、隐式 context 才是 ComfyUI 取消时，旧单链遗漏后者。现在最多遍历 8 个不同异常对象的双分支，取消原对象传播；普通错误仍脱敏、无自动重发。
