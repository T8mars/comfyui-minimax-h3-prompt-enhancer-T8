# Combat Camera：真实 A/B 摘要

2026-09-30，按用户授权使用贞贞平价小屋实际测试生产 H3／Seedance 增强入口。
请求与返回模型均为 `bytedance/doubao-seed-evolving`；8 组初测开／关对照 16 次，
处理问题后追加 10 次复测，共 26 次生成，均 HTTP 200、finish_reason=stop。
首尾帧＋Relay 使用实际上传的两张 PNG 示意图，两臂共 4 次上传成功。
不是视频生成、真实 GGUF 推理、完整 UI 排队或 RunningHub 部署验收。

每对使用相同输入、素材、模型、seed、表演设置、温度 0.7、max_tokens=16384；
关闭其他质量／因果编排流程，只改变战斗运镜配置。B 为强化＋偏好连续镜头＋写实。
评分为人工、非盲、小样本文本评价：事实归属 25、明确约束 25、运镜可读性 25、
因果终态 15、原生格式 10，不代表成片效果或显著性。

## 初测不能跳过的问题

- H3 固定双镜头两臂都用了中文时间码逗号。A 把衣袖写成袖套，B 写成护臂；
  初测分别 86／82 分，均不能因总分而忽略违规。
- POV 的“手持微动”和“不拍身体”可与眼位视点／入镜手部冲突。
- 动态样本的正文时长保留不稳定，强化并不总比关闭好。

现在完整原生 H3 输出会仅修复实际镜头时间码逗号，不改时间数字、对白或可见文字，
不增加模型调用；开启规则明确衣物不变装备、眼位 POV 不等于手持摄影机、
指定手部可入镜，并提醒保留时长。语义规则不是确定性合规保证。
