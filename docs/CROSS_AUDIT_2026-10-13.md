## 已确认并修复的 8 类问题

| 编号 | 复现与影响 | 修复及回归证据 |
| --- | --- | --- |
| B1 地址/传输 | 大写 `HTTPS://` 通过 URL 校验，却因原始文本前缀判断走 HTTP；显式端口 `:0` 被替换为默认端口。隔离 HTTP 服务实际收到前者的请求及测试 Bearer 值，未使用真实凭据。 | 根据解析后的 scheme 选 TLS；显式零端口拒绝。回归确认 TLS 连接尝试、HTTP 端零请求。 |
| B2 配置校验 | `False`、`0`、空列表/字符串被当成缺省配置；超大整数在浮点校验时泄漏 `OverflowError`。 | 只允许 `None` 表示缺省，非对象拒绝；先检查范围再浮点转换。错误分类为 configuration，不默默接入默认服务。 |
| B3 协议/消息错误边界 | 畸形 choices、HTTP 400 error.message、capabilities/video/limits 容器可产生 `AttributeError` 或误报连接错误；列表型 role/type 可产生 unhashable `TypeError`。 | 显式容器和字段类型校验，输出安全分类错误；无效文本 part 拒绝。畸形状态/消息在 POST 前停止，畸形完成响应不作为成功。 |
| B4 服务锁 | 另一个线程持锁时，首次等待被取消，客户端已提前缓存；第二次访问同一运行对象可返回未持锁客户端。 | 成功持锁后才缓存；close 清除客户端/锁引用。真实 RLock 等待、取消、再次访问及关闭后重新获取均有回归。 |
| B5 只读状态 | 服务在线、未加载、auto_load=false 时，只读检查误报“连接未通过”。视觉 enabled=true/available=false 也显示得不准确。 | 分开 connected、ready、loaded、auto_load 与视觉可用性；提示手动加载。只读仍仅 GET；生成仍在未就绪时零 POST 拒绝。 |
| B6 Reroute 界面 | 共享 Strata 配置经 Reroute 连接时，后端用 Strata，前端却显示旧云端/GGUF 控件；远端连线改变未刷新增强节点。 | 有界、循环安全地解析 Reroute；兼容 Map/object links。合并连接变化刷新并保留宿主回调/返回值、旧值和 inactive 尺寸。Node 与 Chrome 合同覆盖。 |
| B7 图片资源检查顺序 | 已知超大/无效形状的 tensor 在被拒绝之前先 detach/to(cpu)/float，可能产生不必要的大量分配。 | 已知 shape 在转换之前校验，转换后仍校验有限像素和原上限。侦测对象证明非法形状不会触发 detach；没有人为制造真实 OOM。 |
| B8 严格保留歌词 | 作词节点选 Strata 后使用 Preserve，不调用模型，报告却访问空 snapshot，实际报 `NoneType` 错误。 | 无调用时模型报告留空、UI 标记 not-used。直接选择/共享配置两种入口都原样返回歌词和报告，零客户端、零 GET/POST，包括勾选文本审校的原行为。 |

实现集中在 Strata 新增文件及作词报告的 Strata 分支；原渠道分支不改写，未新增主节点字段或序列化位置。

## 明确保留的边界

不宣称“所有 BUG 已消失”。未部署 RunningHub，未对所有旧 GGUF 模型或云渠道重新付费验收；原路径验证为现有离线/冻结合同回归。未生成视频/音乐成片。

本轮不触碰 `roadmap.md`、凭据/运行状态、GGUF、用户私有文档或用户服务生命周期；授权发布按 PATCH 递增为 1.31.1，并单独核验 Actions/Registry。
