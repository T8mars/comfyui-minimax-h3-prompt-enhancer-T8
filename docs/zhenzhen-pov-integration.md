# 贞贞 POV 独立技能接入记录

日期：2026-09-28。发布目标：插件 `1.25.0`；最终发布状态以 GitHub Actions 和 Registry 为准。

请求：将用户提供的 `zhenzhen-pov-director-1.5.9-20260928` 快照改编成本项目独立技能。主代理与一个独立审查子代理实际进行了20次顺序议题往返，最后再分别实施与复核。以下是决策摘要，不是20次模型生成或视频效果评测。

旧行为基线：`20689b34b8d4239540bfea933052a9ae8d44a931`（1.24.6）。新资源 ID：`zhenzhen_pov`；首版资源／共享授权合同版本：`1.0.0`。来源快照版本是 `1.5.9`，与插件发布版本、资源版本分开。

## 20轮决策摘要

| 轮次 | 议题 | 采纳的结论或修正 |
| --- | --- | --- |
| 1 | 接入位置 | 复用两节点的独立技能下拉；必须接通授权、质量、恢复全链路，不能只加资源文字。 |
| 2 | 人物与默认视点 | 署名不定义人物；眼睛POV仅用于无冲突人物互动；第三人称及无人物任务不强改，也不追加不适用报告。 |
| 3 | 摄影归属 | 区分眼睛、持机、自拍；转头不等于切镜，高度可随身体动作改变；关键交接不能靠切镜跳过。 |
| 4 | 主角度 | 按站坐关系与观看目标选择，不强塞三角度英文标签，不为机位添凳子或台阶。 |
| 5 | 模型触发词 | 默认不加；H3仅条件性保留用户原始要求，放所选模式合法正文；共享资源与Seedance增量不含专用触发句。 |
| 6 | 素材职责 | 使用真实media plan与顺序；身份图不变首帧、首尾锚点不变身份图；不读私有身份配置。 |
| 7 | 对白授权能力 | 新建AUTHORING_SKILLS能力集合；原DRAMA_SKILLS来源家族不变。核心、Bible、因果与纠正使用同一授权能力。 |
| 8 | 静默与结尾 | 即使极致／因果开启也不填补无回应；声源时序受实际信息约束，保留有根据的先知／假装，不强迫反转或冻结。 |
| 9 | 物理连接 | 核对动作起点、操作者、占用手、可达路径与末态；身体可见范围按实际任务，不统一限制“只许手”。 |
| 10 | 剧情可读性 | 普通演法反读、揭示顺序、最难动作排期；简化无用准备但保留戏眼，不把选择改成普通递物微笑。 |
| 11 | 时长与镜数 | 保留现有平台接受的参数范围与AUTO逻辑；不给POV硬设一镜、15/20秒或16:9，不重排锁定动作。 |
| 12 | 叠加与任务 | 沿既有模板暂停规则；补充局部编辑、延长、补轨边界，覆盖H3尾帧模式；Relay事件不是镜头。 |
| 13 | 纠正与失败 | 复用既有修复预算，不新增评分调用；完整稿保留有前提，不能承诺所有失败都有结果。 |
| 14 | 恢复与缓存 | 保存有限ID／版本，不新增自由元数据；恢复不按当前技能重创作；切技能影响真实Comfy输入签名。 |
| 15 | 前端兼容 | 保持38个保存字段和第35索引的技能ID；测试实际显示顺序与保存顺序不同、反复切换及旧图。 |
| 16 | 示例 | 双平台各一独立图，空Key；用等待指向后放空白卡片验证动作合同，不把入门示例包装成高分剧情。 |
| 17 | 来源边界 | 独立改写、相对文件路径与七份SHA-256；不分发原文、生产器、个人资产或批次记录，不套用其他来源许可。 |
| 18 | 验证边界 | 自动测试工程合同、真实浏览器DOM、独立ZIP加载；不以替身或关键词断言冒充真实机位、语义或成片验收。 |
| 19 | 改动范围 | 不修改旧六份资源／八例，不新增节点、端口、重试、付费调用；保留用户已有未跟踪文档，不推送。 |
| 20 | 最终裁决 | 无阻断项，同意实施。主代理实现，子代理独立写专项测试并只读复核实现。 |
