# Reviewed source excerpt

This folder retains unmodified official Skill text, selected references, an example
and the Apache-2.0 license at the revision in `source.json`. It is not a standalone
YuE2 installation: upstream audio scripts and model setup assets are intentionally
not bundled. Follow links in the [full official Skill](https://github.com/multimodal-art-projection/YuE/tree/92a73cc7652fcc1f937855e4b765e0a0edd7ff2e/skills/yue2-music)
for audio generation. The node uses the adapted ABC helper in `yue2_abc.py`.

Registry packages omit `references/generation-and-covers.md`, an audio-runtime
tutorial containing executable examples unrelated to this text-only node. Its
unaltered original remains in GitHub and upstream; `source.json` records its hash
and repository-only status. All packaged prompt/ABC references remain verified.
