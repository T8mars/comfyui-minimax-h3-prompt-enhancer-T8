# MiniMax H3 official prompt-writing Skill snapshot

`h3-prompt-writing/` is an exact, normalized snapshot of the portable official
prompt-writing Skill from
[`MiniMax-AI/MiniMax-H3`](https://github.com/MiniMax-AI/MiniMax-H3) at commit
`d21241f0a4b3acbb34c97dae47fa417b7065e438`.

It contains only the four files needed by the portable core Skill:

- `SKILL.md`
- `agents/openai.yaml`
- `references/base-en.txt`
- `references/ref-en.txt`

`H3_SOURCE.json` records the exact commit and normalized file/tree hashes. The
node injects only the guide matching the selected H3 task. The eight Hub-native
scene Skills remain represented by the node's reviewed creative presets and
are not copied into this portable core snapshot.
